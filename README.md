# 📝 درباره پروژه

این پروژه یک پیاده‌سازی خلاقانه و مدرن از بازی نوستالژیک **دوز (Tic-Tac-Toe)** در فضای سه‌بعدی و بدون نیاز به تاچ، موس یا کیبورد فیزیکی است.

برنامه با استفاده از دوربین سیستم، دست کاربر را در فضا اسکن کرده و نوک انگشت اشاره او را به عنوان قلم یا نشانگر بازی در نظر می‌گیرد. بازیکنان می‌توانند با نگه‌داشتن انگشت خود روی هر خانه از جدول به مدت کمتر از یک ثانیه (مکانیزم هوشمند Hover-to-Click)، علامت خود را (دایره آبی یا ضربدر قرمز) ثبت کنند.

نرم‌افزار به صورت هوشمند برنده بازی یا حالت مساوی (Tie) را تشخیص داده و خط پیروزی را روی صفحه رسم می‌کند.

---

# ⚡ ویژگی‌های فنی و الگوریتم‌های پردازش تصویر

- **ردیابی لندمارک‌های دست با MediaPipe Hands:**  
  بهره‌گیری از خط لوله پیشرفته یادگیری ماشین برای استخراج مختصات دو بعدی نوک انگشت اشاره (`INDEX_FINGER_TIP`) با نرخ فریم بالا و تأخیر نزدیک به صفر.

- **الگوریتم منطقی زمان‌سنجی تعاملی (Hover Trigger):**  
  اگر انگشت کاربر به مدت `0.9` ثانیه در محدوده یک خانه خالی باقی بماند، انتخاب ثبت شده و نوبت تغییر می‌کند.

- **موتور تشخیص برنده و ترسیم خط پیروزی (Win-Line Render):**  
  پس از تشخیص یکی از حالت‌های برد، خط پیروزی به صورت داینامیک روی تصویر رسم می‌شود.

- **دکمه مجازی بازشروع (Virtual Play Again Button):**  
  در پایان بازی، کاربر می‌تواند با نگه داشتن انگشت روی دکمه مجازی، بازی را ریست کند.

# 🚀 راهنمای جامع دانلود، نصب و راه‌اندازی (قدم به قدم)

## 📥 مرحله اول: دانلود فایل کد از گیت‌هاب

### روش اول — دانلود کل پروژه
از بالای همین صفحه روی دکمه سبز رنگ **Code** کلیک کرده و گزینه **Download ZIP** را انتخاب کنید. سپس فایل دانلود شده را از حالت فشرده خارج کنید.

### روش دوم — دانلود مستقیم فایل
در لیست فایل‌های پروژه، روی فایل پایتون کلیک کرده و سپس گزینه **Download raw file** را بزنید تا فایل مستقیم دانلود شود.

---

## 🐍 مرحله دوم: نصب پایتون

اگر پایتون روی سیستم شما نصب نیست:

1. وارد سایت رسمی Python شوید.
2. آخرین نسخه را دانلود و نصب کنید.
3. هنگام نصب حتماً تیک گزینه زیر را فعال کنید:

```text
Add Python to PATH
```

---

## 📦 مرحله سوم: نصب کتابخانه‌ها و پیش‌نیازها

1. وارد پوشه پروژه شوید.
2. دکمه `Shift` را نگه دارید و راست‌کلیک کنید.
3. گزینه **Open PowerShell window here** یا **Open in Terminal** را انتخاب کنید.
4. دستور زیر را اجرا کنید:

```bash
pip install opencv-python mediapipe numpy
```
